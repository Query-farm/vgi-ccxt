## Setup

Colab installs only the base shared package **v0.3.50**; compatible preloaded plotting/data/kernel libraries stay in place. `prepare("ccxt")` downloads one immutable SHA256-verified companion, [fixtures.json](fixtures.json). No manual checkout or domain helper is needed. Local publication uses the optional runner:

```sh
uv sync --locked --extra runner
uv run --locked --extra runner vgi-notebooks
```

Run those commands from this directory. Notebook Python supports 3.11–3.14; the independently launched worker needs Python 3.13 or newer, which uv can provision. Install [uv](https://docs.astral.sh/uv/) and Git. The first shared-package, worker and VGI extension installation requires network access. The visible SQL launch is:

```sql
INSTALL vgi FROM community;
LOAD vgi;
ATTACH 'ccxt' (TYPE vgi,
 LOCATION 'uvx --from git+https://github.com/Query-farm/vgi-ccxt@v0.1.0 vgi-ccxt-worker');
```

The release owns its dependencies. No transitive `--with` overrides, root source directory, local worker binary or worker build is needed. The notebook lock is independent of the root lock. Shared `connect(globals())` creates empty temporary SQL-secret storage, disables persistent secrets and saved JupySQL INI connections, and establishes UTC before any cursor is created. Empty inventories are checked before ATTACH and cleanup; no secrets are created. Fixture selection is explicit and the previous `VGI_CCXT_FIXTURES` value is restored at cleanup, with an exit fallback.

## Synthetic provenance and limits

The fixture is byte-identical to [the released test input](https://github.com/Query-farm/vgi-ccxt/blob/b8d02c64b618bd74c9bbea689de4c62897a69d78/test/fixtures/exchanges.json), SHA256 `6d4af927d0c7c98dcc51943d0ee54890e64269b2f5c5161e942911fdb387f4ed`. Its source clock is fixed at **1 January 2026 UTC**. Earlier historical series, page caps, deterministic values and deliberate capability differences come from the released fixture generator. There is no silent live fallback.

Book 01 retains the original substantive SQL, interpretation and returned tables. Its half-open window is **[26 January, 5 February 2024) UTC**. Unsupported history, a supported empty window, zero rates and nonzero observations remain distinct. The interval transition and multi-page scan exercise the worker's inference; spacing-based inference can be ambiguous when real rows are missing. `rate × 8760 / hours` is simple annualization for a 365-day year, not compounded return or a forecast.

Book 02 deliberately separates measurement contracts. The roster describes four fixture identities, market definitions carry contract sizes, and snapshot fan-outs retain failure rows with NULL values. Current funding describes an upcoming settlement; its fixture generator uses the configured eight-hour interval independently of Book 01's historical interval transition. Open-interest amount is contracts **or** base currency under the worker contract. We test an explicit contracts assumption against reported value; the fixture's reported value is generated as amount × price regardless of contract size. The 100× OKX stand-in disagreement therefore cannot establish the true unit or a live exchange conversion. The separate Binance **spot** book has BTC quantity and USDT/BTC prices. More requested levels reveal more fixture rows, not a fill guarantee.

Book 03 requests **[1 January 2024 00:00, 01:00) UTC** from both histories. The known generator has 60 minute candles and 120 trade events, with one to three IDs sharing a timestamp. Candle and trade prices/volumes are independent synthetic generators, so they are not reconciled as a real exchange tape. Row caps can end inside a timestamp group; distinct IDs remain necessary. Plotted spans use timestamp labels consistently, not an inferred continuous coverage interval. Real retention, omissions and exchange timestamp precision can differ.

```sh
uv run --locked --extra runner vgi-notebooks 01_funding_rates_need_intervals.ipynb --parameters '{"ASSUMED_HOURS":4}' --output-dir validation/assumed-4

uv run --locked --extra runner vgi-notebooks 03_a_row_cap_is_not_a_time_window.ipynb --parameters '{"MAX_ROWS":80}' --output-dir validation/rows-80
```

Overrides require a separate destination. The shared runner rejects unknown parameters and preserves the last successful default/experiment if execution fails. Defaults embed native SVG and use content-addressed SVG image links for GitHub; experiment copies retain native SVG. Logs, experiment copies and review images remain ignored. One fresh preloaded Python 3.12 notebook-only run validates the common launcher/companion path for all three stories. A hosted Colab session is not claimed.

## Optional public live reads

The worker exposes only unauthenticated read methods. For a deliberately separate live session, leave `VGI_CCXT_FIXTURES` unset **before launching the worker**, retain isolated SQL-secret storage, and use the same visible ATTACH. Do not rerun the synthetic notebook's assertions as claims about a live exchange. A separate bounded `ticker('okx','BTC/USDT')` read passed through the released worker with fixture mode removed; no live values enter these analyses. Other methods, venues and times are not established by that one successful read. Rate limits, regional restrictions and unavailable symbols remain possible; inspect `error` and never replace missing observations with zero or synthetic fallback.
